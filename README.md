# All In One POS (Flutter & Dart)

A cross-platform Point of Sale (POS) & Business Management System engineered for **Windows, Android, iOS, and macOS**.

## 🚀 Key Features
- **🏪 Dual Pricing**: Instant toggle between Retail and Wholesale prices.
- **🖨️ Universal Thermal Printing**: Supports 58mm, 72mm, and 80mm ESC/POS thermal printers via Bluetooth, USB (OTG), and Network IP.
- **💬 WhatsApp Digital Invoices**: Send formatted digital receipts directly to customer WhatsApp numbers.
- **💰 Real Net Profit Calculation**: Tracks Cost Price (COGS) vs Selling Price vs Business Expenses.
- **📊 Reports & Analytics**: Interactive charts with instant one-tap PDF and Excel (CSV) exports.
- **🛠️ Integrated Modules**:
  - 🔧 Repair Jobs & Service Tickets
  - 🔄 Returns & Refund Processing
  - 👥 Customer Ledger & Credit / Loan Tracker
  - 🌅 Day End Closing & Cash Drawer Settlement
  - ⏸️ Held Bills Manager
  - 🏷️ Barcode Label Designer

## 💻 How to Run
1. Install Flutter SDK (https://flutter.dev).
2. Run `flutter pub get` to download dependencies.
3. Launch on any platform:
   - **Windows**: `flutter run -d windows`
   - **Android**: `flutter run -d android`
   - **iOS / macOS**: `flutter run -d macos` or `flutter run -d ios`
   - **Chrome / Web**: `flutter run -d chrome`
